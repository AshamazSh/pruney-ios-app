Name
Pruney: 사진과 동영상 정리

Subtitle
추억은 남기고 공간은 넓게

Promotional Text
새로운 추억을 위한 공간을 만드세요. 스와이프로 사진과 동영상을 확인하고, 필터로 골라 크기를 줄이세요. 평생 Pro 구매로 작업 횟수를 무제한으로 이용하세요.

Description
간직하고 싶은 순간을 위해 공간을 만드세요. Pruney는 사진 보관함을 확인하고, 삭제할 항목을 선택하고, 지원되는 사진과 동영상의 크기를 줄이는 앱입니다.

보관함을 한눈에
사진, Live Photos, 동영상의 접근 가능한 파일 크기를 보여줍니다. 측정값은 기기의 정확한 저장 공간 사용량이나 보장되는 확보 용량을 뜻하지 않습니다.

스와이프로 선택
왼쪽으로 밀어 삭제를 선택하고, 오른쪽으로 밀어 보관하고, 위로 밀어 크기를 줄이세요. Live Photos는 위로 밀면 정지 사진으로 변환됩니다. 선택을 되돌리거나 남은 항목에 작업을 한꺼번에 선택할 수 있습니다. 확인하는 동안 파일은 바뀌지 않습니다.

시작 전에 필터 적용
미디어 종류, 생성 날짜, 파일 크기를 선택하세요. 한 필터에 조건을 결합하거나 대체 필터를 추가할 수 있습니다.

축소 수준 선택
지원되는 사진과 동영상에는 약하게, 균형, 강하게, 최대의 네 단계가 있습니다. 사진은 원본 가로와 세로의 90%, 80%, 70%, 50%를 유지합니다. 파일 크기의 비율이 아닙니다. 동영상은 호환되는 낮은 해상도를 사용합니다. 지원되는 사진 형식을 유지하며, Live Photos는 움직임 없는 일반 사진으로 바꿀 수 있습니다.

확인한 뒤 실행
시작 전에 선택한 작업을 확인하세요. 크기 축소와 정지 사진 변환은 대체 파일을 저장하고 원본을 삭제합니다. 사진 앱에서 시스템 확인을 요청할 수 있습니다. 파일은 최근 삭제된 항목에 최대 30일 동안 남습니다. 즉시 공간을 확보하려면 해당 앨범을 직접 비워 주세요.

무료로 시작
한 세션에서 최대 50개 삭제와 10개 축소 또는 정지 사진 변환을 사용할 수 있습니다. 보관에는 제한이 없습니다. Pruney Pro는 한 번 구매해 평생 작업 횟수를 무제한으로 이용하는 선택 상품이며 구독이 아닙니다.

사진에 대한 전체 접근 및 제한된 접근을 지원합니다. 분석과 크기 필터는 클라우드에만 있는 파일을 다운로드하지 않습니다. 지원되지 않는 미디어는 확인 대상에서 제외됩니다.
