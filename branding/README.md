# Pruney brand assets

`Pruney-Pro-Lifetime-1024.png` is a separate 1024 × 1024 opaque PNG for the Pruney Pro lifetime in-app purchase. The plum retains the app's visual identity; a gold PRO label distinguishes the lifetime purchase. The current artwork has no infinity symbol. This artwork is provided for upload and is also embedded in the purchase sheet through the PruneyPro image asset; it is not installed as the app icon.

`Pruney-AppStore-1024.png` is the standalone App Store icon: 1024 × 1024 pixels, opaque PNG, with a full-bleed square background. It is identical to `Pruney/Assets.xcassets/AppIcon.appiconset/Pruney-AppIcon.png`. Do not add rounded outer corners; iOS applies the corner mask.

The transparent logo is stored in `Pruney/Assets.xcassets/PruneyMark.imageset/PruneyMark.png`. It is used by the native launch storyboard and onboarding. Adaptive launch colors are separate color assets.

## Artwork generation

Both images were created with the built-in imagegen tool from the user-approved simplified-plum concept. The icon was normalized to 1024 × 1024 after generation. The source previews remain outside the project.

### App icon prompt

Create the final standalone production iOS app icon for Pruney from the APP ICON at left in the reference. Output ONE square 1024x1024 artwork, full bleed deep plum purple #41205F background to ALL four sharp square corners. NO rounded outer corners, NO border, NO outside whitespace, NO text, NO presentation labels. Preserve the reference refined brand mark: ONE continuous simple asymmetric oval light lilac plum, subtly tilted right, slight notch at top, one mint leaf above leaning right, one white four-point sparkle within upper-right fruit. Match its proportions and gentle lilac gradient, almost flat vector artwork, no extra side lobe, no extrusion, no seam, no shadows. Fruit and leaf together centered as a group both horizontally and vertically, ample even breathing room, occupying about 70 percent canvas height and 60 percent width. Crisp professionally finished edges. No changes to the chosen design. Only extract and finish the square icon from the reference concept; no mockups.

### Transparent mark prompt

Extract the EXACT plum-and-leaf brand mark from the provided final Pruney app icon onto a genuinely transparent background. Remove ONLY the purple background. Preserve precisely the single light-lilac tilted plum silhouette with top notch, mint leaf above, white four-point sparkle and existing soft gradients. Match original silhouette, orientation, colors, relative position and size; do not redesign. Output a square transparent PNG, preserve the same canvas composition and margins as input. No purple square, no shadow, no text, no extra elements, no checkerboard baked into image. This is the same logo used in the app icon, for the native launch screen and onboarding.

### Lifetime purchase icon prompt

Use case: logo-brand. Asset type: standalone App Store in-app purchase promotional icon for Pruney Pro Lifetime, a one-time lifetime unlock, NOT a recurring subscription.

Create ONE premium square 1024x1024 graphic matching the provided approved Pruney app icon. Full-bleed opaque deep plum purple #41205F background extending to all four SHARP square corners. No rounded outer frame or outside whitespace.

Preserve the brand's same ONE smooth tilted light-lilac plum silhouette, subtle top notch, one mint leaf above leaning right, gentle lilac gradient, simple flat vector-like finish. Keep the same recognizability and proportions of the reference.

Premium distinction: replace the original white four-point sparkle INSIDE the upper-right fruit with a single crisp warm GOLD infinity symbol, centered comfortably within the fruit's upper-right area. Infinity is a clean elegant continuous rounded stroke, readily legible, no coin or medallion. No additional sparkle, crown, ribbon, badge or objects. Below the fruit-and-leaf mark place exact text "PRO" in elegant bold clean sans serif uppercase, warm gold #F5D58C, subtle letter spacing. No other words, no Pruney wordmark, no prices or subscription claims.

Composition: logo centered above PRO with generous padding. Fruit-and-leaf together occupy about 62 percent canvas height, PRO below occupies about 7 percent height with comfortable breathing room. Center the complete mark-plus-PRO composition on the canvas; generous symmetric outer margins. Premium, restrained, friendly, crisp finished edges, no glossy 3D extrusion, no busy textures, no photographic lighting, no shadows. This must look like a coherent member of the Pruney brand, clearly distinguishable from the app icon. Output ONLY the square final graphic, no mockups or presentation sheet.

This icon was created with the built-in imagegen tool and normalized to exactly 1024 × 1024. Its dimensions and lack of transparency were checked. No app code changed; no build or tests were run for this asset.
